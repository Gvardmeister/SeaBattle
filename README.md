# SeaBattle (Морской Бой)

Классическая игра "Морской бой", реализованная на Go. Игра в консоли против ИИ (пока что — в однопользовательском режиме для тестирования логики).

## Архитектура

Проект структурирован по принципам [Чистой архитектуры]

- cmd/ — точка входа
- internal/domain/ — бизнес-логика
  - game/ — логика игры (ходы, завершение, переходы)
  - player/ — логика реализации игроков (человек, ИИ)
  - board/ — логика доски и размещения кораблей
  - ship/ — логика кораблей (статус, попадания)
- internal/services/ — служебные компоненты
  - stdgenerator/ — логика реализации рандомизации (координаты размещени)
  - stdinputreader/ — кастомная структура для bufio.reader
- internal/test/ — mock-тесты
  - mocks/mockcoordinategenerator/ — моки для тестирования координат
  - mocks/mockinputreader/ — моки для тестирования ввода
- internal/interfaces — интефейсы
- pkg/ — сторонник пакеты и утилиты
- cover — конфигурационный файл, покрытие тестов
- go.mod — модуль версии программы
- README.md — документация проекта

## Установка и запуск

1. Убедитесь, что установлен Go (версии >= 1.20).
2. Склонируйте репозиторий:

```bash
    git clone https://github.com/Gvardmeister/SeaBattle.git
    cd seabattle
```

``` bash
3. Запустите игру:
    go run cmd/main.go
    или можно  запустить двойным кликом по exe-файлу
```

## Управление

- Введите координаты. Формат: {1 1}, чтобы стрелять по полю или 'y' для выхода.
- . — промах
- X — попадание
- @ — неизведанная клетка

## Возможности

- Генерация поля и кораблей по правилам
- Проверка валидности размещения
- Поддержка интерфейса игрока
- Простая CLI-интерфейсная логика
- Расширен для игры против ИИ (PvE-режим)
- Расширен для игры против друго игрока (PvP-режим)
