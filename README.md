# SeaBattle (Морской Бой)

Классическая игра "Морской бой", реализованная на Go
Игра в консоли против ИИ (пока что — в однопользовательском режиме для тестирования логики).

## Архитектура

Проект структурирован по принципам [Чистой архитектуры]

- cmd/ — точка входа
- internal/domain/ — бизнес-логика
  - game/ — логика игры (ходы, завершение, переходы)
  - player/ — интерфейсы и реализации игроков (человек, ИИ)
  - board/ — логика доски и размещения кораблей
  - ship/ — логика кораблей (статус, попадания)
- pkg/ — общие пакеты, утилиты, если есть

## Установка и запуск

1. Убедитесь, что установлен Go (версии >= 1.20).
2. Склонируйте репозиторий:

```bash
    git clone https://github.com/your-username/seabattle.git
    cd seabattle
```

``` bash
3. Запустите игру:
    go run cmd/main.go
    или можно  запустить двойным кликом по exe-файлу
```

## Управление

- Вводите координаты X и Y от 1 до 10, чтобы стрелять по полю.
- . — промах
- X — попадание
- @ — неизведанная клетка

## Возможности

- Генерация поля и кораблей по правилам
- Проверка валидности размещения
- Поддержка интерфейса игрока
- Простая CLI-интерфейсная логика
- Возможность расширения под ИИ/сетевую игру
