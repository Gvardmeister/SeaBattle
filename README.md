# SeaBattle

Морской бой

Есть игровое поле 10х1, на нем размещается один корабль 4 палубы, пользователь вводит координату, получает ответ в формате «вы попали» если попал, поле обновляется. «Вы выиграли» когда корабль убит.

Например, начинается игра

Введите координату
Пользователь вводит 5

На экране надпись: Вы попали
@@@@Х@@@@@

Введите координату
Пользователь вводит 4
Вывод: Вы промахнулись
@@@.Х@@@@
Потом, после нескольких итераций

Вы выиграли!
@@@.ХХХХ@@
